# Mile High Noise — Unofficial Broncos Fan HQ

Fun, bright, unofficial Denver Broncos fan page with:

- Hero hype + stadium atmosphere
- **Broncos Ring** — sports-card slider (drag / swipe / arrows)
- **Hype Board** — star player blurbs
- AI sports-card art (foil-frame direction)

Not affiliated with the NFL or the Denver Broncos.

## Local

Open `public/index.html` in a browser, or:

```bash
npx serve public
```

## Stack

Static HTML / CSS / JS. Deploy-ready for Vercel or GitHub Pages.
